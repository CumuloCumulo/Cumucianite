A dark Obsidian theme with a deep blue-black palette and electric cyan accents, inspired by the album artwork of SawanoHiroyuki[nZk].

Based on [Obsidianite](https://github.com/bennyxguo/Obsidian-Obsidianite) by Benny Guo.

---

## Color Palette

| Role | Color |
|---|---|
| Background | `#080e18` |
| Panel background | `#0d1822` |
| Primary accent (cyan) | `#00d8f2` |
| Secondary accent (lime) | `#3dff8a` |
| Body text | `#c0d8e8` |
| Links | `#60c8e8` |

## Features

- Deep blue-black backgrounds with clear depth layering
- Electric cyan headings, tags, and interactive elements
- Neon lime green for italic text, heading underlines, and HR decoration
- Bold text rendered as a cyan → lime gradient
- Dracula-based code syntax highlighting
- Custom styled blockquotes, checkboxes, tags, and inline code
- Subtle animated checkbox interactions

## Installation

### Community Themes (recommended)

1. Open Obsidian **Settings → Appearance → Themes**
2. Click **Manage** and search for `Cumucianite`
3. Click **Install and use**

### Manual

1. Download `theme.css` and `manifest.json` from this repository
2. Create a folder named `Cumucianite` inside your vault's `.obsidian/themes/` directory
3. Place both files inside that folder
4. In Obsidian, go to **Settings → Appearance → Themes** and select `Cumucianite`

## Requirements

- Obsidian 1.1.0 or later
- Dark mode
